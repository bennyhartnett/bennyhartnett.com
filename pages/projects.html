IoT · Edge Computing · Deployed

Wildfire detection from remote fire towers

Perimeter · 2021

Designed and developed an IoT system for real-time wildfire detection in remote, high-risk areas where connectivity, weather exposure, and reliable field operation all matter.

Challenge

Turn a remote fire tower into an automated thermal observation point that can scan its surroundings, capture useful imagery, and attach location context without depending on local wired infrastructure.

Approach

Combined Raspberry Pi edge computing, a FLIR thermal camera, servo-driven scanning, GSM connectivity, AWS S3 image storage, and Google Maps geolocation inside a durable waterproof enclosure.

Outcome

The resulting system was deployed on fire towers in remote high-risk areas across the United States, integrating sensing, motion, connectivity, cloud storage, and mapping into one field-ready platform.

  • Raspberry Pi
  • FLIR
  • GSM
  • AWS S3
  • Google Maps
Nuclear · Web Engineering · Client Tool

Uranium enrichment calculations in the browser

Centrus Energy · 2025

Built a specialized browser-based calculator that turns uranium assay inputs into the quantities needed for enrichment planning and analysis.

Challenge

Provide a focused workflow for enrichment calculations without requiring a heavyweight desktop application or a general-purpose spreadsheet.

Approach

Implemented the calculation workflow in HTML and JavaScript so users can compute feed quantity, separative work requirements, and optimum tails assay directly in the browser.

Outcome

Delivered a purpose-built tool for Centrus Energy and made the calculator available as an interactive web experience on the nuclear section of this site.

  • JavaScript
  • HTML
  • SWU
  • Numerical Modeling
